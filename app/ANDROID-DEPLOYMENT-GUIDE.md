
# راهنمای انتشار اپلیکیشن اندروید در گیت‌هاب از طریق موبایل

این راهنما یک نمای کلی از مراحل لازم برای انتشار کد منبع یک اپلیکیشن اندروید در گیت‌هاب، مستقیماً از طریق یک دستگاه موبایل با استفاده از یک محیط لینوکسی (مانند آنچه Andronix فراهم می‌کند) ارائه می‌دهد.

**پیش‌نیازها:**
1.  **محیط لینوکس روی موبایل:** اپلیکیشنی مانند Andronix برای داشتن یک خط فرمان لینوکسی کامل.
2.  **نصب Git:** اطمینان از اینکه `git` در محیط لینوکس شما نصب شده است.
3.  **حساب کاربری گیت‌هاب:** شما به یک حساب کاربری در GitHub.com نیاز دارید.

---

### مرحله ۱: آماده‌سازی پروژه اندروید

فرض بر این است که شما سورس کد پروژه اندروید خود را در یک پوشه مشخص در حافظه موبایل خود دارید.

1.  **ورود به محیط لینوکس:** اپلیکیشن Andronix خود را باز کنید و وارد محیط لینوکس شوید.

2.  **رفتن به پوشه پروژه:** با استفاده از دستور `cd` به مسیری که سورس کد پروژه اندروید شما در آن قرار دارد بروید.
    ```bash
    # مثال:
    cd /path/to/your/android/project
    ```

---

### مرحله ۲: آماده‌سازی گیت (Git)

اگر این اولین بار است که از گیت استفاده می‌کنید، نام و ایمیل خود را پیکربندی کنید. این اطلاعات در تاریخچه کامیت‌های شما ثبت می‌شود.

```bash
git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"
```

---

### مرحله ۳: ساخت یک ریپازیتوری (Repository) در گیت‌هاب

1.  با مرورگر موبایل خود به سایت `GitHub.com` بروید و وارد حساب کاربری خود شوید.
2.  روی آیکون `+` در بالا سمت راست کلیک کرده و گزینه‌ی `New repository` را انتخاب کنید.
3.  یک نام برای ریپازیتوری خود انتخاب کنید (مثلاً `MyAndroidApp`).
4.  آن را به صورت `Public` (عمومی) یا `Private` (خصوصی) تنظیم کنید.
5.  **مهم:** گزینه‌ی "Initialize this repository with a README" را تیک **نزنید**.
6.  روی دکمه `Create repository` کلیک کنید.

در صفحه‌ی بعد، گیت‌هاب به شما آدرس URL ریپازیتوری را نشان می‌دهد. چیزی شبیه به: `https://github.com/YourUsername/MyAndroidApp.git`. این آدرس را کپی کنید.

---

### مرحله ۴: اتصال پروژه محلی به گیت‌هاب و انتشار

حالا به محیط ترمینال لینوکس روی موبایل خود برگردید. مطمئن شوید که در پوشه‌ی پروژه خود هستید.

1.  **ایجاد یک ریپازیتوری گیت محلی:**
    ```bash
    git init
    ```

2.  **افزودن تمام فایل‌های پروژه به گیت:**
    ```bash
    git add .
    ```

3.  **ایجاد اولین کامیت (Commit):**
    یک کامیت مانند یک عکس فوری از وضعیت فعلی پروژه شماست.
    ```bash
    git commit -m "First commit: Initial project setup"
    ```

4.  **تغییر نام شاخه اصلی به `main`:**
    این یک استاندارد جدید و رایج است.
    ```bash
    git branch -M main
    ```

5.  **اتصال ریپازیتوری محلی به ریپازیتوری گیت‌هاب:**
    از آدرس URL که در مرحله قبل کپی کردید استفاده کنید.
    ```bash
    git remote add origin https://github.com/YourUsername/MyAndroidApp.git
    ```
    *   `YourUsername` و `MyAndroidApp.git` را با مقادیر واقعی خود جایگزین کنید.

6.  **پوش (Push) کردن کد به گیت‌هاب:**
    این دستور، کدهای شما را از موبایل به سرورهای گیت‌هاب ارسال می‌کند.
    ```bash
    git push -u origin main
    ```

    *   در این مرحله، گیت از شما نام کاربری و رمز عبور (یا یک Personal Access Token) گیت‌هاب را خواهد پرسید تا هویت شما را تایید کند.

---

**تبریک می‌گویم!** اگر تمام مراحل با موفقیت انجام شده باشد، کد منبع اپلیکیشن اندروید شما اکنون در گیت‌هاب منتشر شده است و شما می‌توانید آن را در صفحه ریپازیتوری خود مشاهده کنید. این قدرت خلق و انتشار از هر کجا و با هر وسیله‌ای، دقیقاً روح حاکم بر «شهر توانا» است.
