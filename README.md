# LinguaWeave - Your AI Language Learning App

This is your Next.js project for LinguaWeave.

## How to See Your App

To see and interact with your application, follow these simple steps:

1.  **Open a terminal or command line** in the root directory of this project.
2.  **Run the following command:**

    ```bash
    npm run dev
    ```

3.  **Open your web browser** and go to the address that appears in the terminal (usually `http://localhost:9002`).

You will now be able to see your app and click through all the pages we've built together!
